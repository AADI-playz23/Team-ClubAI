## 📖 Overview

**Browser-Agent-Squad** is an open-source, serverless framework that allows a team of AI agents to collaborate, review, and finalize tasks—entirely in your web browser. 

Designed to be ultra-lightweight, this project requires **zero backend servers** and runs flawlessly on standard hardware without heavy local compute. Just provide your API keys, and the built-in JavaScript orchestrator handles the routing of context between different AI "personas" automatically. 

### 🤝 The AI Team Workflow

When a user submits a prompt, the orchestrator triggers a turn-based workflow:
1. 🧠 **The Architect:** Drafts the initial codebase, structure, or solution.
2. 🔍 **The Reviewer:** Critiques the Architect's work, looking for bugs, optimizations, and security flaws.
3. 👑 **The Senior Lead:** Takes the original prompt, the draft, and the critique, and synthesizes them into a perfect, production-ready final output.

## ✨ Features

* **100% Client-Side Compute:** All orchestration runs in the browser. Zero server costs and instant deployment via GitHub Pages.
* **BYOK (Bring Your Own Key):** Users supply their own API keys, which are securely stored locally on their machine.
* **Persistent Local Memory:** Chat history and context are saved natively via browser storage, ensuring no data is lost between sessions.
* **Customizable UI:** Features a sleek, modern glassmorphism dark mode, designed to be easily customized with anime-inspired aesthetics or team branding.
